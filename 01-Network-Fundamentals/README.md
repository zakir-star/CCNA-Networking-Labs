# 01 — Network Fundamentals

This module covers end-device addressing and the fundamentals needed to verify local connectivity.

## Labs

- ✅ [PC-to-PC Connectivity](../PC-to-PC-Connectivity/README.md) — static IPv4 addressing, subnet masks, and `ping` verification.
- 🔜 IPv4 Addressing and Subnetting — network IDs, usable host ranges, and broadcast addresses.
- 🔜 IPv6 Addressing Basics — IPv6 formats, address types, and client configuration.

Supporting topology images and Packet Tracer files remain in each existing lab folder.
